# 짧은 실제 손떨림 미검출 원인 분석(판정 규칙 5 기준)

분석일: 2026-11-21. 기준 커밋: `99a10d2`(`main`, 판정 규칙 5). Issue #27·#26. [판정 규칙 5 기록](sharpness-half-scale-shake.md)의 후속이다.

## 요약

- **판정 코드는 바꾸지 않았다.** 오탐을 늘리지 않으면서 짧은 실제 손떨림을 더 찾는 단일 사진 판정 후보를 찾지 못했다.
- RealBlur 최종 검증용(holdout) 손떨림 150장 중 흐림 판정이 1장뿐인 원인은 두 가지다.
  1. **흔들림이 감지 한계보다 짧다(`선명` 104장).** 같은 장면의 선명 사진과 비교해 추정한 흔들림 길이는 중앙값 약 3.5화소다. 같은 선명 사진에 직선 흔들림을 넣어 보면 현재 판정은 중앙값 24화소부터 흐림으로 본다. 흔들린 방향의 점수도 선명 사진의 약 절반으로 줄 뿐 임계값 `0.025` 아래로 내려간 사진은 없다.
  2. **흔들린 사진 쪽 잡음이 미세 경계를 대신 채운다(`분석 불가` 45장).** 이 사진들은 짝인 선명 사진보다 추정 잡음이 크고(중앙값 1.56 대 0.88), 사진 전체의 미세 경계 세기가 선명 사진과 거의 같다. 잡음 기준을 풀어도 흐림 신호가 남아 있지 않다.
- RealBlur 사진(약 680×770)은 분석 크기(긴 변 1024px)보다 작아 **축소 없이 원래 크기로 분석한다.** RealBlur의 미검출은 축소 때문이 아니다.
- 휴대폰 원본(예: 4032×3024)은 약 1/4로 줄여 분석하므로 원본에서 수~20화소인 짧은 흔들림은 분석 크기에서 1~5화소가 되어 같은 감지 한계 아래로 들어간다. 더 큰 크기로 분석하는 방식은 이전에 잡음 증가로 기각했고(2048px 실험), 원본 크기 일부 영역 분석은 짧은 흔들림이 있는 휴대폰 원본 정답 자료가 없어 평가하지 못했다.
- 같은 장면의 선명·흔들림 사진을 **서로 비교하면** 대부분 흔들린 쪽 점수가 낮다. 비슷한 사진 묶음 안의 상대 비교는 다음 후보지만, 화면·추천 방식이 바뀌는 별도 기능이라 이번에 구현하지 않았다.

## 1. 기준값(판정 규칙 5, 캐시 재판정)

[판정 규칙 5 기록](sharpness-half-scale-shake.md) 5절과 같다. 이번에 dev를 현재 `main`으로 다시 판정해 같은 값을 확인했다(Chromium 분석용 이미지 캐시. WebKit 캐시는 2026-11-17 기록에서 사진 단위로 같음).

각 칸은 `흐림 판정 / 선명 판정 / 분석 불가`다.

| 묶음 | 선명 정답 | 초점 흐림 정답 | 움직임 흐림 정답 |
|---|---|---|---|
| Kwentar dev 각 193장 | 0 / 74 / 119 | 27 / 18 / 148 | 28 / 42 / 123 |
| Kwentar holdout 각 157장 | 0 / 63 / 94 | 24 / 16 / 117 | 26 / 29 / 102 |
| RealBlur dev 각 552장 | 0 / 395 / 157 | — | 4 / 363 / 185 |
| RealBlur holdout 각 150장 | 0 / 114 / 36 | — | 1 / 104 / 45 |

- 판정 규칙 5의 효과: Kwentar 움직임 흐림 holdout 6 → 26장. 선명 정답 오탐 0 → 0.
- 남은 한계: Kwentar 흐림 정답의 `선명` 놓침(움직임 흐림 dev 42장 등)과 선명 정답의 분석 불가(Kwentar 약 60%), 그리고 아래의 짧은 실제 손떨림.

## 2. 방법

RealBlur는 같은 순간을 두 카메라로 찍은 선명(gt)·흔들림(blur) 쌍이라 장면 차이를 빼고 흔들림만 볼 수 있다. dev 552쌍으로 원인을 분석했고, holdout 150쌍은 후보를 고르지 않고 같은 진단 분포만 한 번 확인했다.

- 판정·측정값: 현재 제품 판정 코드(`measureSharpness`, `classifySharpness`)를 분석용 이미지 캐시에 그대로 실행했다.
- 흔들림 방향: 사진 전체의 방향별(가로·세로·두 대각선) 2차 차분 분산을 쌍끼리 나눠, 가장 많이 줄어든 방향을 흔들린 방향으로 본다.
- 등가 흔들림 길이: 선명 사진을 그 방향으로 길이 L의 직선(상자) 흐림으로 흐렸을 때 같은 비율만큼 줄어드는 L을 보간한다. 실제 궤적은 휘어 있을 수 있어 **대략적인 길이**다. 흔들린 사진의 잡음이 커서 미세 경계가 줄지 않은 쌍은 길이를 잴 수 없다(1.4화소 이하로 나온다).
- 감지 한계: 같은 선명 사진에 흔들린 방향의 직선 흐림(3·5·8·12·16·24·32화소)을 넣어 현재 판정을 실행했다. 상자 흐림은 잡음도 함께 줄여 실제보다 찾기 쉬운 조건이다.

## 3. 결과

### RealBlur 흔들림 사진의 판정별 특성

| 흔들림 사진 판정 | dev | holdout | 흔들린 사진 잡음 중앙값 | 짝 선명 사진 잡음 중앙값 | 등가 흔들림 길이 중앙값(dev) |
|---|---:|---:|---|---|---:|
| 선명 | 363 | 104 | 0.38 / 0.37 | 0.91 / 0.88 | 3.5화소(10~90%: 1.8~5.6) |
| 분석 불가 | 185 | 45 | 1.44 / 1.56 | 0.89 / 0.88 | 잴 수 없음(미세 경계가 줄지 않음) |
| 흐림(모두 `흔들림 의심`) | 4 | 1 | 0.29 / 1.52 | — | 5.7·5.8·7.0·16.0화소 |

잡음 칸은 `dev / holdout`이다.

- 흔들린 방향의 점수: dev 흔들림 사진 중 그 방향을 판정한 444장 **모두 0.025 이상**이다(중앙값 0.149, 같은 장면 선명 사진의 같은 방향 0.282). 흔들림 근거는 "끌린 방향은 흐림"이 전제라 성립하지 않고, 근거 구역이 하나라도 있는 288장에서도 끌린 방향이 선명한 반대 구역이 중앙값 13개다(dev). 검출된 dev 4장은 흔들림이 5.7화소 이상으로 길고 잡음이 작은 사진이다.
- 분석 불가 185장은 모두 판정하지 못한 방향이 있고, 사진 전체 미세 경계 세기의 흔들림/선명 비율이 중앙값 1.01이다. 흐림으로 사라진 미세 경계를 잡음이 채운 상태라 잡음 기준을 바꿔도 흐림을 구분할 근거가 없다.

### 감지 한계(같은 선명 사진에 직선 흔들림, dev 552장)

| 흔들림 길이(분석 크기 화소) | 3 | 5 | 8 | 12 | 16 | 24 | 32 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 흐림 판정 | 0 | 27 | 94 | 144 | 207 | 288 | 328 |
| 그중 `흔들림 의심` | 0 | 0 | 18 | 51 | 121 | 232 | 291 |

- 흐림으로 판정되는 최소 길이의 중앙값은 24화소(10%: 8화소)다. 실제 흔들림 길이가 이 최소 길이에 닿은 쌍은 552쌍 중 9쌍이다.
- 직선 3화소 흐림을 넣은 선명 사진의 흔들린 방향 점수(중앙값 0.084)보다 실제 흔들림 사진(0.149)이 높다. 실제 RealBlur 흔들림은 대부분 3화소 직선 흐림보다 약하다.

### 단일 사진 기준으로 갈리는지

| 특징 | 분리도 AUC dev / holdout | 의미 |
|---|---|---|
| 점수(현재 판정의 핵심 값) | 0.712 / 0.694 | 장면마다 점수 차이가 흔들림에 의한 차이보다 크다 |
| 방향별 점수 최소/최대(방향성) | 0.535 / 0.546 | 거의 구분하지 못한다 |
| 분석 크기 흔들림 근거 구역 수 | 0.676 / 0.640 | 근거 구역 자체가 0~4개에 그친다 |

AUC 0.5는 무작위, 1.0은 완전 분리다. dev 선명 정답 중 가장 낮은 점수(0.039)를 기준으로 삼아도 그보다 낮은 흔들림 사진은 552장 중 9장(1.6%)이다. 이 값조차 dev에 맞춘 기준이라 채택할 수 없다.

## 4. 이미지 축소의 영향

- **RealBlur**: 약 680×770이라 축소 없이 분석한다. 흔들림 길이 약 3화소는 원래 해상도의 값이며 축소로 잃은 근거가 아니다.
- **휴대폰 원본**: 긴 변 4032px 사진은 약 1/3.9로 줄인다. 위 감지 한계(분석 크기 8~24화소)는 원본에서 약 31~94화소의 직선 흔들림에 해당한다. 원본에서 수~20화소인 짧은 손떨림은 분석 크기에서 1~5화소가 되어 감지되지 않는다. 축소가 짧은 손떨림 근거를 잃게 만드는 것은 맞다.
- **더 크게 분석하는 방식**: 이전 2048px 실험(Kwentar dev, [공개 실제 사진 평가](sharpness-real-photo-evaluation.md) 4절 D)은 잡음과 질감도 함께 커져 움직임 흐림의 분석 불가가 크게 늘고 검출이 줄었다. 2048px에서 분석 불가일 때 1/2로 다시 보는 방식도 Kwentar dev 움직임 흐림 8장 검출, 선명 정답 오탐 1장이었다(2026-11-10, 판정 규칙 2 시점 코드).
- **원본 크기 일부 영역(크롭) 분석**: 이번에 측정하지 않았다. 짧은 흔들림이 있는 휴대폰 원본 정답 자료가 없다. Kwentar 움직임 흐림은 크게 휘두른 흔들림이고 RealBlur는 이미 작은 크롭이다. 큰 원본 디코딩의 메모리·시간 비용(2026-11-17 WebKit 실행은 메모리 부족으로 중단됨)도 함께 검증해야 한다.

## 6. 한계

- 등가 흔들림 길이는 4방향 직선 흐림 가정의 근사다. 휘어진 궤적·회전 흔들림은 반영하지 못한다.
- 합성 감지 한계는 선명 정답 사진 위의 직선 상자 흐림이다. 실제 흔들림(카메라 처리·압축 포함)과 다르고, 상자 흐림이 잡음도 줄여 실제보다 찾기 쉬운 조건이다.
- RealBlur 라벨은 촬영 의도이며 사람이 다시 확인하지 않았다. RealBlur 원본은 2026-11-16에 지워져 분석용 이미지 캐시로만 분석했다.
- 휴대폰 원본의 짧은 손떨림 정답 자료가 없다. 위 4절의 휴대폰 원본 수치는 감지 한계를 축소 배율로 환산한 값이며 실제 휴대폰 사진에서 잰 값이 아니다.
