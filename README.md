# AI Dev Starter

AI Agent와 프로젝트를 시작할 때 사용하는 기술 스택 중립 개발 스타터입니다. 공통 컨벤션, 작업 계획, 문제 분석, 독립 리뷰와 Git·PR 규칙을 제공합니다.

## 프로젝트 시작

1. 이 저장소의 **Use this template**으로 새 저장소를 만듭니다.
2. Agent가 [AGENTS.md](AGENTS.md)와 [프로젝트 초기 설정 체크리스트](.ai/checklists/project-init.md)를 읽게 합니다.
3. 요구사항과 디자인 방향을 정하고, 핵심 기술 스택은 후보와 장단점을 검토한 뒤 사용자가 선택합니다.
4. `AGENTS.md` 아래의 프로젝트별 설정을 채우고 새 작업 브랜치에서 개발합니다.
5. 리뷰 게이트를 사용하려면 [설정 안내](.ai/checklists/review-gate-setup.md)에 따라 새 저장소의 브랜치 보호를 별도로 설정합니다. GitHub의 보호 설정은 템플릿 파일과 함께 복사되지 않습니다.

프로젝트의 실행·설치·테스트 명령은 기술 스택을 정한 뒤 기록합니다. 이 README도 실제 프로젝트 소개와 사용법에 맞게 갱신합니다.

## 선택 도구: Claude Code에서 Codex 리뷰 요청

Claude Code로 구현하는 경우 [Codex plugin for Claude Code](https://github.com/openai/codex-plugin-cc)를 개발자 컴퓨터의 Claude Code에 선택적으로 설치해 사용할 수 있습니다. 설치 방법과 지원 명령은 사용 시점의 저장소 README를 확인합니다.

- 필수 설치가 아닙니다. 플러그인을 쓰지 않으면 별도의 Codex 등으로 필요한 독립 리뷰를 진행합니다.
- 역할은 **Claude 구현 → 구현에 참여하지 않은 Codex 검토 → Claude 수정 → 필요한 재검토**로 나눕니다. 같은 창에서 요청하더라도 실제 검토자가 별도의 Agent인지 확인합니다.
- 자동 리뷰는 기본적으로 끄고, 구현과 로컬 검사가 정리된 시점에 필요한 리뷰를 직접 요청합니다. 매 응답마다 실행하거나 같은 변경을 중복 검토하도록 설정하지 않습니다.
- PR 전체를 검토할 때는 최신 기준 브랜치와 작업 브랜치의 전체 차이를 대상으로 합니다. 미커밋 변경만 검토하고 이미 커밋한 변경까지 검토했다고 보고하지 않습니다.
- 검토 중에는 대상 코드를 바꾸지 않고, 결과에 기준 커밋과 검토 대상 커밋, 검토 범위, 지적사항과 실행하지 못한 검사를 남깁니다. 검토 후 코드가 바뀌면 해당 변경을 다시 확인합니다.
- 실행 중·취소·스킵·한도 초과는 검토 완료로 처리하지 않습니다. 결과를 실제로 읽고 차단 지적의 해결 여부를 확인합니다.
- AI 실행에는 계정의 사용량이 소모됩니다. 추가 과금을 허용하지 않는 프로젝트에서는 사용 가능한 구독 범위를 확인하고, 한도에 도달하면 멈춥니다. 유료 API나 추가 결제로 자동 전환하지 않습니다.
- 로컬 로그인 정보와 인증 파일을 저장소에 복사하거나 커밋하지 않습니다.

이 플러그인은 검토를 요청하는 선택 도구입니다. 기존 CI, 필요한 독립 검증, PR 결과 기록과 사람 확인을 대체하지 않습니다. 플러그인의 자동 리뷰 기능과 이 템플릿의 GitHub `independent-review` 검사는 서로 다른 기능입니다.

## GitHub 리뷰 게이트

기본 `independent-review` 게이트는 **AI를 호출하지 않고**, 최신 변경에 대한 리뷰 근거와 관리자의 확인 기록을 검사합니다. 자동 병합은 기본으로 사용하지 않습니다.

- [리뷰 게이트 설정과 확인 댓글 형식](.ai/checklists/review-gate-setup.md)
- [위험도와 독립 검증 기준](.ai/policies/verification.md)
- [리뷰 자동화 정책](.ai/policies/review-automation.md)
- [커밋·PR·병합 메시지 규칙](.ai/policies/git-messages.md)

필요한 독립 리뷰는 도구 설치 여부와 관계없이 수행합니다. 검토 결과가 있어도 최신 변경에 대한 CI와 필요한 사람 확인을 거쳐 병합합니다.
